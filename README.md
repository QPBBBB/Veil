# Veil

- **开发环境**：Unity **6000.6.3f1**，工程目录为 `UnityProject/`。
- **渲染管线**：HDRP **17.7.0**，使用 **Linear（线性）色彩空间**。
- **光照标准**：采用基于物理的光照，使用物理光照单位与色温。当前正午参考场景使用物理天空，太阳光 **100,000 lux / 6,500 K**，固定曝光 **EV100 = 14**。

一款使用 Unity 开发的实时战术沙盒独立游戏，以单位自主行为和分层指挥为核心。玩家下达高层命令，单兵、小队与载具依据各自掌握的情报自主行动，在地形、通信和资源限制下完成任务。

核心循环：**下达指挥 → 自主执行 → 情报反馈 → 调整决策**。时代、装备与战场可按场景配置。

## 待实现模块

- **场景与模拟**：模拟时间、实体管理、场景配置，以及地形、建筑和交互物件。
- **单位与装备**：通用人形 Pawn、骨骼与动画、角色外观、装备和能力配置。
- **行动与 AI**：导航、走跑、跳跃翻越、寻找掩体、任务执行与受阻恢复。
- **战斗与资源**：站定、移动及掩体射击，命中、伤害、弹药与死亡表现。
- **感知与通信**：视野遮挡、单位认知、情报汇报与共享，区分战场实况和已知信息。
- **指挥与任务**：命令校验、任务分解与结果反馈，统一接入玩家、内置逻辑及外部大模型指挥。
- **组织与协同**：小队分工、多队编组、资源协调，以及载具驾驶、乘员和上下车。
- **表现与观察**：模型、动画、音效，以及俯视、自由、跟随和随身相机。
- **诊断与复盘**：状态检查、事件记录、性能分析与回放。

## 近期目标

先完成可复用的人形 Pawn 及基础动作，再逐步串联指挥、行动、观察与反馈，形成内容规模有限、核心体验完整的可玩 Demo。
